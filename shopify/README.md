# Dossier Shopify : la vraie boutique Honey Mommy

Commence par **`PLAN.md`** : il explique tout, dans l'ordre.

| Fichier | À quoi il sert |
|---|---|
| `PLAN.md` | Le plan complet : coûts, profits, étapes, trafic, obligations légales, calendrier |
| `PROMPT-SOURCING.md` | Le texte à coller dans l'extension Claude (Chrome) pour trouver des centaines de produits |
| `theme/REGLAGES.md` | Couleurs, polices, page d'accueil, menu et page produit du site |
| `theme/honey-mommy.css` | Le code de style à coller dans Shopify |
| `pages/PAGES.md` | Les pages du site en anglais : About, FAQ, Shipping, Refund, Become a Partner, Contact |
| `influencers/PROGRAMME.md` | Les réglages UpPromote : codes promo, commissions, niveaux |
| `influencers/CONDITIONS.md` | Les conditions du programme (en anglais) |
| `influencers/MESSAGES.md` | Les messages pour contacter les influenceuses (en anglais) |
